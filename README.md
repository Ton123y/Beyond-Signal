# Beyond Signal

موقع تعليمي احترافي عن ناسا، يضم اختبار معلومات من 5 مستويات، ولوحة متصدرين، ولعبة ثلاثية الأبعاد لتصميم المهمات الفضائية (Mission Lab) يمكن لعبها فردياً أو أونلاين مع فريق حتى 4 لاعبين من أجهزة مختلفة، بالإضافة إلى Scenario Studio لتصميم سيناريوهات جديدة، ودروس، وصفحة مصادر.

> مشروع تعليمي مستقل، غير تابع لناسا وغير معتمد منها.

## التقنيات

- **الواجهة:** React 19 + Vite + Tailwind CSS 4 + wouter، والرسوم ثلاثية الأبعاد بـ three.js و @react-three/fiber.
- **الخادم:** Node.js + Express + tRPC، واللعب الجماعي اللحظي بـ Socket.IO على المسار `/api/socket.io`.
- **قاعدة البيانات:** MySQL عبر Drizzle ORM (الجداول: `quiz_scores` و `mission_runs` و `scenarios` و `mission_rooms`).

## التشغيل محلياً

المتطلبات: Node.js 22 و pnpm 10 وقاعدة بيانات MySQL.

```bash
pnpm install
# ضع رابط قاعدة البيانات في متغير البيئة DATABASE_URL
pnpm db:migrate        # إنشاء الجداول
pnpm dev               # تشغيل الموقع على http://localhost:3000
```

أوامر أخرى:

- `pnpm build` ثم `pnpm start`: بناء نسخة الإنتاج وتشغيلها.
- `pnpm check`: فحص الأنواع (TypeScript).
- `pnpm db:push`: توليد وتطبيق ترحيل جديد بعد تعديل `drizzle/schema.ts`.

## ملاحظات

- لا يوجد تسجيل دخول: اللاعبون يدخلون باسم مستعار، ولوحات المتصدرين عامة.
- النقاط ونتائج المحاكاة تُحسب على الخادم، لا في متصفح اللاعب.
- الأرقام الهندسية في اللعبة قيم تعليمية مبسّطة وليست بيانات هندسية حقيقية.
